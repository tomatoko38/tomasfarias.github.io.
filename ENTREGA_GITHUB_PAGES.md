# Entrega complementaria: versión estática para GitHub Pages

Se conserva el proyecto original (Flask, plantilla, CSS y bitácora). Se agrega `docs/` como versión estática HTML/CSS para publicar en GitHub Pages, que no ejecuta Flask.

## Publicación
1. Crear un repositorio personal en GitHub y subir todo el contenido del ZIP.
2. Entrar a **Settings → Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**.
4. Seleccionar la rama `main` y la carpeta `/docs`; guardar.
5. Esperar el enlace de GitHub Pages y abrirlo en computadora y celular.
6. Corregir cualquier problema de enlaces, imagen o adaptación móvil y volver a subir los cambios.

## Prueba/corrección sugerida
- Abrir `docs/index.html` localmente.
- Revisar navegación a Presentación, Sobre mí, Proyectos, Habilidades y Contacto.
- Verificar que la foto cargue y que el correo abra el cliente de email.
- Probar ancho móvil; si el menú o el contenido se desbordan, ajustar `docs/estilos.css`.

## Pendientes que requieren la cuenta del estudiante
La creación de cuenta/repositorio, el push y la publicación real en GitHub Pages deben realizarse desde la cuenta personal. No se inventa un enlace publicado.
