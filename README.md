# Portfolio personal — Farias Tomas

Portfolio inicial para presentar mi recorrido como estudiante de 6.º año y mi interés por la nutrición deportiva.

## Ejecutar localmente

1. Instalar Python 3.
2. Abrir una terminal en esta carpeta.
3. Instalar Flask:

   ```bash
   python -m pip install flask
   ```

4. Ejecutar:

   ```bash
   python app.py
   ```

5. Abrir en el navegador: http://127.0.0.1:5000

## Archivos

- `app.py`: servidor Flask.
- `templates/index.html`: estructura y contenido.
- `static/estilos.css`: diseño visual.

## Importante

Esta versión usa Python con Flask y se ejecuta localmente. GitHub Pages no ejecuta Python/Flask; para publicar allí se necesita una versión estática HTML/CSS. No subas datos privados ni contraseñas.
